Assisted manual login checklist

  1. Open login page
  2. Enter username manually (in the screen on the left)
  3. Enter password manually (in the screen on the left)
  4. Enter OTP manually (in the screen on the left)
  5. Confirm you're logged in
  6. Analyze current page

"Open Login Page" resets the lane's tab and navigates — only use it before logging in (using it after login discards that session's tab). "Analyze current page" never navigates; it only reads whatever's already on screen.

🎬 Recorder — record → review → run

Never records a real credential: any password-type field is detected in-page and replaced with a redacted marker before anything leaves the browser — replaying a redacted step fails loudly instead of typing anything. Recording is refused outright while the login page is showing.

Saved scripts CAN run on a schedule or via Telegram /run. Any step whose target text matches a risky keyword (Transfer/Pay/Confirm/Submit/โอนเงิน/ชำระ/ยืนยัน/etc.) always pauses and waits for a live /confirm reply in Telegram before it runs — this is a best-effort keyword match, not a guarantee.
