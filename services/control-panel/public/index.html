Playwright worker

Buttons enqueue a job — a single queue (concurrency 1) serializes access to the shared browser instead of running actions concurrently.

Firefox demo uses Playwright's own patched Firefox build (not the noVNC window's persistent state) — each run gets a fresh, isolated page; nothing carries over between runs.

Workflows

Multi-step workflow definitions from services/worker/workflows/*.json — a generic action registry (navigate/dismissPopup/login/extract/saveSession/screenshot) instead of one fixed script per job.

Gmail (Phase 3 — scaffold)

Gmail API + OAuth scaffold, dev/local only — not wired into the queue or this UI yet. From services/worker: npm run gmail:authorize prints a consent URL to open in your own browser (never automated), then saves the resulting token to a gitignored, unencrypted, dev-only file (data/gmail-tokens/gmail-token.json — a real encrypted vault is a separate, later step). npm run gmail:list proves read access by listing a few message IDs once a token exists.
